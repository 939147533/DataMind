# 2026-10-14 工作日志

## DataMind 项目介绍 PPT 全面重构（V2.0 → V2.1）

**产物**：`docs/DataMind数据库Agent项目介绍V2.1.pptx`（24 页，V2.0 原稿保留）

**背景**：V2.0 由两套生成器拼接而成，存在硬伤：封面白字压白底（副标题 FFFFFF / 标语 DBEAFE / 标签 93C5FD 在纯白背景上不可见）、字体混用（微软雅黑 vs Helvetica Neue）、蓝色两套（0B5FFF/3D8DFF）、大段文字堆叠（P3/P15/P18/P20/P22）、P17 标题重复、P21 表格错位、页码混乱（P3/P4 都是 4，P12 跳过 10）。

**设计系统（科技蓝，已固化）**
- 主色 `0B5FFF`；文字 `0F172A`(标题) / `475569`(正文) / `94A3B8`(弱化)；分隔线 `E2E8F0`；卡片 `F7F9FC`+`E4EAF2`；强调 `22C55E`；危险 `EF4444`；浅蓝底 `EAF1FF`
- 深色页 `0B1830`（封面 / 4 个章节页 / 尾页），浅色页纯白
- 字体统一 **微软雅黑**；页面网格 960×540，左右边距 54，内容宽 852
- 页头：标题 y=42/24pt 加粗 + 蓝色短条 y=82(40×4) + 导语 y=94/11pt；页脚：分隔线 y=498 + 左侧标识 + 右侧两位零填页码（x=883）
- 卡片圆角 `corner_radius=2200`；要点 = 5pt 蓝色圆点 + 文本

**工具链要点（tencent-pptx / editor_sdk）**
- `edsdk.py` 是 JSON-RPC over HTTP 封装，端口 39099–39108；`CODEBUDDY_SKILL_DIR` 未注入时需手动指定 skill 绝对路径
- **新建文本框默认 `wrap="square"` 会自动换行**，左右内边距各 7.2pt、上下 3.6pt；`\n` 不会被转成段落符，多行请用独立文本框
- 加粗/字号/颜色只能事后用 `slide_set_text_property`（`count=-1` 表示到末尾）；**对齐方式无法通过工具设置** → 页码用两位零填充 + 固定 x 实现视觉对齐
- 本机无 LibreOffice / pdftoppm / qlmanage（沙箱受限），**无法渲染预览**；改用几何自检脚本（估算换行高度 + 重叠检测）验证排版
- 保存时 editor 会重编号 `ppt/slides/media/*` 与 `notesSlides/*`，**文件名会变但 rels 同步更新，内容映射正确**（比对 md5 确认），不要被文件名误导

**验证结果**：24 页布局自检 0 疑点；全 deck 字体仅微软雅黑（766 run）；7 页演示的 mp4 + 海报 + 备注全部保留且对应正确。
