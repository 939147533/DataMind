# DESIGN · DataMind 系统技术架构页

## 0. 设计依据

- 未命中 学术 / 商务咨询 / 红金政务 三个预设分支（属技术分享通用场景）→ 走通用设计原则。
- 用户自带**已定稿架构图**，其配色为科技蓝 + 青绿 → 本页色板**从该图取色**，保证图文一体、插回原 PPT 不违和。
- 单页交付，风格克制，不堆装饰。

## 1. 画布与母版（1280 × 720）

| 母版区 | 垂直位置 | 高度 | 内容规则 |
| :--- | :--- | :--- | :--- |
| A · 标题块 | 20–110px | 90px | 标签胶囊 + 主标题 36px bold |
| B · 内容区 | 120–660px | 540px | 左：架构图（L1，520×540）；右：引导句 + 4 条要点（608px） |
| C · 页脚条 | 660–700px | 40px | 左：项目名；右：页码 `01 / 01`，14px 灰字 |
| 页面 padding | 上下 20px、左右 60px | — | 内容可用宽 **1160px** |

高度核算：`20 + 90 + 10 + 540 + 40 + 20 = 720` ✓

## 2. 颜色系统（3 hex）

| 色彩角色 | hex | 用途 | 面积占比 |
| :--- | :--- | :--- | :--- |
| 主色 | `#1B4F8A` | 主标题、要点小标题、要点强调条 | ≤ 15% |
| 强调色 | `#2E9E7B` | 仅用于 A 区「技术亮点」标签胶囊 | ≤ 5% |
| 背景 | `#FFFFFF` | 页面底色 | 剩余 |

- 文本主色 `#0F172A`、次要 `#475569`、页脚 `#94A3B8`。
- **渐变**：不使用（与架构图纯色风格保持一致）。
- **半透明 / 阴影**：不使用。

## 3. 字体系统

- 中文：PingFang SC / 微软雅黑；西文：Inter / Helvetica Neue（商务现代气质）。

| 层级 | 字号 | 字重 | 行高 | 用途 |
| :--- | :--- | :--- | :--- | :--- |
| 主标题（A 区） | 36px | bold | 1.3 | 系统技术架构 |
| 标签胶囊 | 14px | bold | 1.2 | 技术亮点 |
| 引导句 | 20px | regular | 1.5 | B 区顶部一句话立论 |
| 要点小标题 | 19px | bold | 1.4 | 4 条要点标题 |
| 要点正文 | 15px | regular | 1.5 | 4 条要点说明 |
| 页脚 / 页码 | 14px | regular | 1.4 | C 区 |

## 4. 信息密度

- 页面类型：**内容页 · 单主题**；正文 ≈ 220 字（≥ 180 字门槛 ✓）。
- 留白 ≈ 20%（≤ 35% 上限 ✓）。
- 视觉锚点：L1 架构图 520×532，占 B 区面积约 **45%**（≥ 30% 门槛 ✓）。
