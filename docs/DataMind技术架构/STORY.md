# STORY · DataMind 系统技术架构（单页）

## 背景

本页用于插回《DataMind 数据库 Agent 项目介绍》PPT 的「技术亮点」章节，作为**技术架构总览页**。
用户自带一张已定稿的六层架构图，本页以该图为主视觉，右侧配 4 条要点文字。单页独立交付，用户自行复制进原 PPT。

## 单页叙事

- **一句话立论**：分层解耦、职责单一 —— 调用方向 `routers → services → adapters → 目标数据库`。
- **4 条支撑要点**（每条一句，说明"为什么这样设计"）：

| # | 要点 | 一句话说明 |
| :- | :--- | :--- |
| 1 | 分层解耦 | 六层职责清晰：客户端、接入、安全、服务、适配、数据，任一层改动不外溢 |
| 2 | 适配器模式 | 统一 `BaseDBAdapter` 接口按 `db_type` 分发，7 类数据源收敛为 5 套实现，新增数据库只需加一个类 |
| 3 | LLM 统一抽象 | OpenAI 兼容 / Claude / Ollama 共用一套 `chat · stream · ping` 接口，换模型不改业务代码 |
| 4 | 安全纵深 | 登录态 → 路由级 → SQL 类型级三层鉴权，写操作落库待确认并二次校验，全程审计留痕 |
